# Evaluación Oficial ALC / ALCPT · Esc. Mil. Enfría. (versión SIN internet, v0.4.1)

App web instalable (PWA), **exclusiva para evaluaciones formales**: ALC (evaluaciones parciales) y ALCPT (diagnóstico, final y seguimiento, según lo ordenado). No tiene modo de práctica: para practicar se usa «Misión: Obtener la Barra I».

- Un examen solo inicia con el código y el PIN que emite la Administración.
- Los datos de este repositorio son bloques **cifrados** del mismo tamaño, con nombres aleatorios y mezclados con señuelos. No hay lista de formas, títulos, claves de respuesta ni bancos en claro, y nada permite saber qué forma se aplicará.
- Perfiles: Cadete, Docente aplicador, Directora (solo consulta), Usuario piloto (prueba del dispositivo) y Administración.

Ver `INSTRUCTIVO.md`, que incluye las limitaciones reales. Uso interno.
